# Plataforma de Licitações

Front-end reconstruído sobre a estrutura original do tema MaterialM Free Bootstrap Admin enviado pelo usuário.

## Estrutura
- Dashboard
- Radar de Licitações
- Análise de Edital
- Favoritos
- CRM
- Empresas / CNPJs
- Documentos
- Alertas
- Inteligência de Mercado
- Configurações
- Login / Cadastro

A branch `test` é usada para homologação visual antes da integração com PNCP, CNPJ, banco de dados e autenticação real.
