# RadarLicita

Base inicial do painel de inteligência para licitações públicas.

## Stack
- HTML5
- Bootstrap 5.3
- JavaScript puro
- ApexCharts
- Iconify

## Incluído nesta primeira versão
- Dashboard responsivo inspirado no MaterialM Admin enviado como referência
- Sidebar adaptada para Radar, Análise de Edital, Favoritos, CRM, Empresas/CNPJs, Documentos, Alertas e Inteligência de Mercado
- Indicadores de oportunidades, valor, vencimentos e compatibilidade
- Tabela demonstrativa de oportunidades com busca local
- Gráficos demonstrativos
- Tema claro/escuro persistente
- Estrutura estática pronta para deploy na Vercel

## Próximas etapas
1. Consulta de CNPJ/CNAE
2. Integração oficial com PNCP e dados abertos do Compras.gov.br
3. Motor de compatibilidade por palavras-chave, CNAE e itens
4. Tela de análise do edital
5. Alertas por WhatsApp/e-mail
6. Persistência de usuários, empresas e favoritos

> Os dados exibidos no dashboard inicial são demonstrativos. Nenhuma consulta oficial é feita nesta versão.
